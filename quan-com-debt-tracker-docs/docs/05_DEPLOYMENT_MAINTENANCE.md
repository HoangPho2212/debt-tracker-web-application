# 05. Deployment & Maintenance Guide

## 1. Hướng Dẫn Triển Khai Lên Vercel (1 Phút)
1. Đẩy mã nguồn (`index.html` hoặc dự án Vite/Vue) lên GitHub repository.
2. Truy cập [vercel.com](https://vercel.com) -> Chọn **Add New Project**.
3. Import repo GitHub vừa tạo và bấm **Deploy**.
4. Lấy domain miễn phí từ Vercel (ví dụ: `quan-com-no.vercel.app`) gửi cho người sử dụng.

## 2. Hướng Dẫn Sử Dụng Trên Điện Thoại (Dành Cho Chủ Quán)
- **Trên iPhone (Safari):** Mở link web -> Bấm nút **Chia sẻ (Share)** ở thanh dưới -> Chọn **"Thêm vào MH chính" (Add to Home Screen)**.
- **Trên Android (Chrome):** Mở link web -> Bấm dấu **3 chấm** ở góc trên -> Chọn **"Thêm vào màn hình chính" (Install / Add to Home screen)**.
- **Lưu ý quan trọng:** Không mở bằng tab ẩn danh; không bấm xóa dữ liệu/lịch sử duyệt web.

## 3. Quy Trình Sao Lưu Dữ Liệu (Backup/Restore Procedure)
- **Định kỳ (Mỗi tuần 1 lần):** Bấm nút **"Xuất sao lưu (JSON)"** -> Lưu file về Google Drive hoặc Zalo/iCloud.
- **Khi đổi điện thoại mới:** Mở web trên máy mới -> Bấm **"Khôi phục dữ liệu"** -> Chọn file sao lưu đã lưu.
